# SQL Fundamentals

This project contains my SQL learning exercises and mini-projects
using the SalesDB database.

## Topics Covered

- SELECT
- WHERE
- ORDER BY
- DISTINCT
- JOINs
- GROUP BY
- HAVING
- Aggregate Functions
- CASE Statements
- String Functions
- Date Functions
- NULL Handling
- Set Operators
- Window Functions

## Objective

The goal of this project is to strengthen my SQL problem-solving
skills through practical business questions and prepare for a
career in Data Engineering.

## Learning Approach

I am learning SQL by solving small real-world problems and
documenting my solutions, mistakes, and improvements.
